# CVAnalysis 2.1.0

## 新功能与改进

- Liquid Glass 桌面界面及统一设计控件；下拉窗口即时打开，修复黑底过渡。
- CP 多文件容量–循环拼接、逐文件范围和统一 100% 基准。
- LSV / I-T 独立导入与绘图，支持参考面积和参考电容归一化。
- I-T 参考时间标签自动左对齐、按数值排序并限制边界；标签可隐藏或手动定位。
- 多条 I-T 水平参考线：设置数值、颜色、标签、位置及图例；支持双击编辑，默认不进入图例。
- 安全变量模板（如 `{value:.2f}`）、末尾零保留、MathText `$...$` 和公式外 `\n` 换行；拒绝任意 Python 表达式，不调用外部 TeX。
- 白底曲线应用图标用于 Python 启动窗口及两种 Windows 包。

## 下载

- **StandAlone ZIP（推荐）**：解压全部文件后运行 `CVAnalysis_v2.1.0.exe`。
- **OneFile EXE**：单文件运行，首次启动需解压，速度较慢。
- **Source code**：Release 页面自动提供 `v2.1.0` 源码；自行运行需要 Python 3.11+ 及项目依赖。
- 用 `SHA256SUMS.txt` 核对附件。Windows 包为 x64，未签名。

## 项目与数据

项目保留原始数据和每图设置；含 LSV / I-T 的项目使用 v3 格式，旧版程序无法读取。导入、分析与 CSV 导出不因显示归一化或 CP 拼接而修改原始数据。
