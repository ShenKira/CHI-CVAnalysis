# CVAnalysis 2.3.0

## 新功能与改进

- Dunn v5：支持按正扫/反扫分别设置电位选区，可拖动或输入端点；超出共同实测窗口时拒绝并提示。
- Dunn 诊断：拟合与实测电荷、闭合差（超过 ±3% 警告）、相对电流 RMS 残差、净电荷/绝对积分比（低于 10% 提示抵消，低于 0.1% 占比未定义）。
- 新增「Dunn 电位选区与诊断」窗口：CV 与选区预览、拟合与残差、逐扫速诊断表、输入数据表、预览扫速与支路切换。
- 分析 CSV 新增 `dunn_summary.csv`、`dunn_points.csv`、`dunn_inputs.csv`，记录选区、逐扫速、逐电位系数/分量以及参与文件和循环。
- CP/GCD：按原文本数字精度校验 CHI 采样网格；容量、库仑效率和 IR 降可使用验证网格；逐循环记录电位切换时序方法（sampled / estimated / bounded / unavailable）与 CE 范围。
- IR 降在保持段、采样不足、局部非线性或外推方向异常时留空，并按原因汇总到弹窗和底栏日志。
- 图标签页重命名：双击编辑，Enter 或失焦提交，Esc 取消；右键可重命名或恢复自动名称，空名称恢复自动名。名称随项目保存，图内标题独立。
- 论文线宽补偿：自动/全宽/半宽/手动 ×0.10–2.00；曲线、边框、刻度、网格和辅助线按插入尺寸补偿，预览显示系数与源图/论文线宽。
- Dunn 贡献图使用实测扫速类别轴；旧图手动 X 范围按类别索引解释，新图按 V/s，并提示忽略强制统一 X/Y 刻度。

## 下载

- **StandAlone ZIP（推荐）**：解压全部文件后运行 `CVAnalysis_v2.3.0.exe`。
- **OneFile EXE**：单文件运行，首次启动需解压，速度较慢。
- **Source code**：Release 页面自动提供 `v2.3.0` 源码；自行运行需要 Python 3.11+ 及项目依赖。
- 用 `SHA256SUMS.txt` 核对附件。Windows 包为 x64，未签名。

## 项目与数据

项目格式仍为 v3；新增字段带默认值，未知字段保留。Dunn v5 重新计算后可能因积分网格和循环筛选更新而出现数值变化，保存前请核对。分析、CSV 导出和绘图不修改原始测量数据。
