# CVAnalysis 2.2.0

## 新功能与改进

- Dunn 电荷分解支持拟合（1/√v 外推）与实测两种 100% 基准，可并排或堆叠显示；柱形布局与百分比重算统一使用带符号电荷。
- 数据树勾选与当前图实时联动：切换标签只回填该图的文件/循环选择；多图导入默认不勾选，单图时自动加入同类新文件；未应用的右下参数在定向刷新后保留。
- 修正 b 值与 Trasatti 的扫速一致性校验、Trasatti 总电荷外推、CV 逐循环电荷、CP/GCD 完整性检查与 IR 降、EIS 快速几何估计。
- 分析与绘图警告统一显示在非模态弹窗和底栏红字日志，画布只保留数据与正常图注。
- 构建清单显式包含 Matplotlib SVG 后端，保证“复制当前矢量图”可用。

## 下载

- **StandAlone ZIP（推荐）**：解压全部文件后运行 `CVAnalysis_v2.2.0.exe`。
- **OneFile EXE**：单文件运行，首次启动需解压，速度较慢。
- **Source code**：Release 页面自动提供 `v2.2.0` 源码；自行运行需要 Python 3.11+ 及项目依赖。
- 用 `SHA256SUMS.txt` 核对附件。Windows 包为 x64，未签名。

## 项目与数据

项目保留原始数据和每图设置；含 LSV / I-T 的项目使用 v3 格式，旧版程序无法读取。导入、分析与 CSV 导出不因显示归一化或 CP 拼接而修改原始数据。
