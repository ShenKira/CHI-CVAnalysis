# 文本、MathText 与换行

版本：2.2.0；本文描述已实现的统一语法，不提供旧版兼容模式。适用于图注、轴标题、图例、参考线标签及文字预设。使用 Matplotlib MathText 子集，无需安装 LaTeX，不支持完整 TeX 或自定义宏。

## 规则与顺序

1. 识别模板文字、`$...$` 数学段及花括号分组。
2. 先安全替换当前上下文已注册的变量，并应用显式数值格式。
3. 保留数学分组并校验 MathText；仅从模板正文解析转义，变量值不递归解释。
4. 屏幕与 PNG / SVG / PDF 等导出使用相同结果。

数学段中的已注册字段优先匹配。例如 `$I_{value:.2f}$` 在值为 2 时生成 `$I_{2.00}$`；`$I_{ref}$` 的 `ref` 若不是已注册变量，则保留为数学下标分组。变量名与数学符号有歧义时，改用不同的下标名称或明确调整公式。

| 输入 | 含义 |
|---|---|
| `I={current:.2f} {unit}` | 安全变量替换，保留指定精度末尾零 |
| `$I_{ref}$` | 数学下标 |
| `$\frac{1}{2}$` | MathText 分数 |
| `first\nsecond` | 数学段外的 `\n` 转为换行 |
| `first\\nsecond` | 字面 `\n`，不换行 |
| `$\nu+\nabla$` | 数学命令保持原样 |
| `{{text}}` | 数学段外的字面花括号 |

实际换行也被保留。MathText 内部反斜杠按数学语法处理，不将 `\nu` 误读为换行。图例原有的空白隐藏约定保持不变；I-T 标签应使用明确的显示开关。

## 校验与安全

编辑窗口提供变量、示例、预览和错误提示；非法模板阻止应用。导入项目或渲染遇到非法数学式时警告并按普通文字回退，避免整个图表无法绘制。

不调用外部 TeX，不处理文件包含、命令执行、动态 Python 表达式或 HTML。模板与格式限制见 [安全变量格式](NUMBER_FORMAT_PLAN.md)；单个数学段上限 512 字符、分组深度 32，MathText 校验缓存最多 256 项。公式字体及可用命令取决于 Matplotlib MathText；中文正文和数学字体分别由绘图设置与数学字体系统处理。

## 实现位置

- `plotting/template_format.py`：统一解析、替换、限制、MathText 校验及回退。
- `plotting/legend.py` / `texts.py`：变量上下文和图例/图注调用。
- `ui/widgets/formatted_text_preview.py`：共用的实时预览。
- `tests_v2/test_safe_template_format.py`：变量与数学分组、换行、恶意输入、资源限制和不递归替换。

新增入口必须复用上述链路，并测试编辑校验、项目往返和实际渲染，避免另写字符串替换逻辑。
