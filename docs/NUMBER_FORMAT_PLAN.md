# 安全变量格式

版本：2.3.0；本文描述已实现行为。模板正文无需 `f` 前缀或引号，例如 `I={current:.2f} {unit}`。这是一种受限的 f-string 风格显示语法。

## 支持范围

数据图例、每图图例覆盖、文字预设、轴标题、I-T 参考点/参考线、CP 曲线图例及各分析图注共用 `plotting/template_format.py`。窗口列出当前上下文的变量并提供提示/预览；不能引用其他窗口才有的字段。普通数字参数框仍只接收数值。

| 模板 | 效果 |
|---|---|
| `{value:.2f}`，值为 1.2 | `1.20` |
| `{value:.3e}`，值为 1.2 | `1.200e+00` |
| `{value:.4g}`，值为 1.2 | `1.200`（保留指定有效数字） |
| `{cycle_n:03d}`，值为整数 2 | `002` |
| `{name}` | 文本变量 |

数字格式支持 `f/F/e/E/g/G/d/%` 及有限的符号、补零、宽度和精度。`d` 只接受整数。显式格式优先于该入口默认的小数位设置；不提供格式时沿用字段默认显示。自带单位的 `DisplayValue` 只格式化数值，保留单位；先做显示单位换算，再格式化。格式化不改变分析精度或原始数据。

## 安全边界

- 仅按注册变量查找；禁止调用、运算、属性、下标、动态精度、嵌套字段及 `!r` 转换。不会执行 `eval`、`exec` 或 Python f-string。
- 格式化仅接受受控文本、内置/白名单 NumPy 数值，以及 `DisplayValue` / `DisplayRange`；不调用任意外来对象的 `__str__` / `__format__`。
- 数值必须有限。上限：模板 4096 字符、128 字段、输出 16384 字符、宽度 128、精度 12。
- 编辑校验阻止非法输入；导入或渲染中的无效模板安全回退并警告，不执行、不覆盖原模板。
- 变量值不做二次变量替换或转义解析。公式分组规则见 [文本与公式语法](TEXT_MARKUP_PLAN.md)。

## 扩展与验证

增加变量时须同时更新真实上下文、变量列表、校验和示例，使用类型化显示值传递单位与默认文本。预览、屏幕与导出共用同一解析器。安全和末尾零的核心回归位于 `tests_v2/test_safe_template_format.py`；各入口的测试分别覆盖保存、项目往返和渲染。
