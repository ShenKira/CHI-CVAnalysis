# CVAnalysis 修正与功能验收报告

更新日期：2026-10-26。本报告替代上一版问题清单，记录当前修正状态与验证边界。

## 使用方式

“分析参数”和“论文尺寸与字号”固定在 GUI 右下方，属于主窗口内部控件，不再弹出独立窗口。底栏默认约 400 px 高，左侧日志与右侧选项之间的分隔条可调整宽度并持久保存。旧布局首次升级会启用新底栏；“视图 → 重置布局”可恢复默认布局。选项跟随当前图切换，没有图时禁用编辑。

- 电容–扫速：一次函数、按显示坐标拟合直线、幂律拟合或不拟合；X/Y 轴可分别选择自动、线性或对数。图例统一根据最终图形显示 `Fitted Line` 或 `Fitted Curve`。误差棒和拟合线可分别关闭。误差棒表示参与统计循环的标准差，不是置信区间。隐藏拟合线仍可保留拟合注释；选择不拟合则移除拟合及其注释。
- 固定电位电流与 b 值：提供目标电位。
- Dunn 电流分解：提供分解扫速。
- EIS 图：提供频率上下限，留空表示不限；错误会在原窗口内显示。
- 所有图：图例、坐标轴、分析注释及论文版面尺寸。

## 论文宽度与字体

这里将“默认10号”解释为 **10 pt**，界面使用 pt 明确标注。版心宽度默认 160 mm，指页面宽度扣除左右页边距后的可用宽度，可自行调整。

论文中的插入宽度 = 版心宽度 × 占比。支持 0.5、0.33、0.25；也接受 `0/25` 表示 0.25。0 不表示有效占比，关闭补偿复选框即可恢复预设字号。改变占比不会改变逻辑画布尺寸或 DPI；PNG/TIFF 的 DPI 可在导出时单独调整。

| 元素 | 正文字号比例 | 正文 10 pt 时 |
|---|---:|---:|
| 标题 | 1.00 | 10 pt |
| X/Y 轴标题 | 0.90 | 9 pt |
| 刻度、图例 | 0.80 | 8 pt |
| 注释 | 0.75 | 7.5 pt |

上表是缩放到论文后希望达到的字号。实际插入缩放比例 `s = 论文插入宽度(mm) / 源图宽度(mm)`；源图宽度来自当前预设画布英寸数乘以 25.4。**源图字号 = 论文目标字号 / s**。如果源图宽度正好等于版心宽度，插入为 50% 时，最终需要 10 pt 的文字在源图里应设为 20 pt，25% 时应设为 40 pt。

当页面占比严格小于 0.33 时，为了在固定画布内保持可排版性，所有补偿后的图中文字字号额外乘以 0.8；此时最终字号为表中目标字号的 80%。占比等于 0.33 时不触发该缩小。

图例支持自动、图内和图外三种位置。自动模式下，占比小于可调阈值时外置，默认阈值为 0.5；图例列数可自动按可用宽度计算，也可指定 1–8 列。单坐标轴图的外置图例放在底部，Bode 图放在顶部，EIS 拟合图在右侧预留图例区域；多坐标轴外置时合并重复系列名，拟合图同时列出残差系列。

启用论文布局时，X/Y 轴标题与刻度标签间距从 Matplotlib 默认的 4 pt 调整为 2 pt；图外底部图例按实测高度预留空间，避免固定底边距造成轴标题与图例之间留白过大。

所有预设统一使用 3.2 in 高，宽度由画布比例计算。例如 4:3 画布宽度约 4.27 in，300 DPI 时导出约 1280 × 960 px；版心 160 mm、占比 0.5 时实际缩放约为 80/108.4 ≈ 73.8%，轴标题源字号约为 9/0.738 ≈ 12.2 pt，放进论文后为 9 pt。界面显示固定分辨率、插入宽度、缩放比例、源字号和论文字号。

补偿每次从不变的逻辑画布尺寸重新计算，不会在重复应用或导出时叠加放大；不使用 tight 裁边改变画布。复制和图片导出采用相同补偿。请在论文中按设定宽度插入，否则字号会相应改变。

窄幅电容–扫速图使用简短轴标签和紧凑 R² 注释，图例移到图外。画布使用统一逻辑高度，不再根据预览控件尺寸改变 Figure 英寸尺寸；预览只调整 DPI 并按比例缩放以适应可用区域，布局字号比例与导出保持一致。条目太多时可关闭图例或增加占比。

## 上一轮评审逐项处理

| 原问题 | 本次处理 |
|---|---|
| 统计均值、SD、计数采用不同样本 | 统一使用裁剪后样本；有效数、排除数、极值同步；CSV 增加 included_in_statistics。设置明确改名为固定数量裁剪，保留既有计算策略，避免误认为阈值异常检测。 |
| CV 积分面积误标为 C | 数据树改为 A·V，CSV 使用 integral_area_A_V，另提供除以扫速的 loop_charge_C。保留内部 area_C 兼容字段，新增正确命名的属性；电容公式保持不变。 |
| 导入线程未结束就关闭窗口 | 文件边界支持中断；窗口延迟关闭直到线程 finished，不再超时后销毁活动线程。 |
| 旧异常循环标记残留 | 每次计算指标前清理派生状态，放宽阈值后可恢复正常循环。 |
| 拟合、导入后分析、项目加载阻塞 | TaskThread 承担拟合与项目读取/分析，ImportThread 承担导入和初始分析；使用隔离数据快照，结果回主线程应用；关闭时等待任务完成。重复拟合有保护。 |
| 项目无法完整复现实验 | 项目格式 v2 内嵌解析后的原始数值数组及元数据，保存分析设置、拟合参数/数组和预设快照；恢复时映射 ID，源文件移走仍能恢复。兼容读取 v1，项目/绘图未知字段保留。 |
| 非法频率静默变成不限 | 主分析区与选项窗口均拒绝非数字、NaN、Infinity、非正数和倒置范围；保留留空语义，错误原位显示。 |
| CHI 提示乱码 | 修复数据表头、数据点不足、无效值、缺扫速/灵敏度、跳行等中文错误和警告。 |
| 多 EIS 图例遮挡曲线 | 大量条目移至图外；论文模式在固定画布内为图例预留位置，不降低目标字号。 |
| 主窗口职责和机器绑定打包 | 新增独立任务 worker、分析选项对话框和论文排版模块；build.bat 基于脚本目录和当前 Python 环境执行，移除机器绝对路径，提前检查依赖。 |
| 启动时 Qt6Widgets 访问冲突（0xC0000005） | 右下固定面板改变了主窗口 dock 布局，但启动仍恢复旧版 `saveState()`。布局首次迁移时跳过旧 dock 状态，只恢复窗口几何和确定性的底部默认位置；关闭后写入 `ui.bottom_layout_version=2`，后续会话再恢复新版状态。 |

项目恢复的分析配置保存在会话中，不直接覆盖全局配置。明确保存设置后才将新设置用于会话。项目保存的是已解析的数据，不是原始文本字节；原始文件也应按实验归档要求保留。

## 验证边界与后续维护

- 没有运行耗时的 Nuitka 全量打包，也没有执行真实桌面的多屏/DPI 人工验收。
- 正在执行的单次文件读取或 SciPy 求解不能被硬终止；关闭会等待它返回，避免线程销毁崩溃。
- 交互重绘仍在 GUI 线程；极大数据集、很多同时打开的图仍有优化空间。主窗口继续拆分控制器属于后续维护工作，当前已经将新增计算与选项逻辑分离。
- 极窄图片搭配很多图例或复杂多子图可能拥挤；建议关闭图例、采用短别名，或选择更大的页面占比，不自动改变分辨率或降低字号。
- v1 项目仍依赖原路径；成功读取后另存为 v2 可转为内嵌数据项目。
